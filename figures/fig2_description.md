# Figure 2: Convergence Diagnostics (M = N)

双面板图 (7 × 2.8 inches)，展示蒙特卡洛模拟的收敛性诊断。

数据来源：`data_N{8,16,32,64,100,128}.dat`，每个尺寸 121 个温度点 (T/J = 0.05 ~ 1.0)。
模拟参数：10^8 measurement sweeps, 2×10^6 thermalization sweeps, 200 jackknife bins。

---

## Panel (a) — 接受率 (Acceptance Rate) vs T/J

- **X 轴**: T/J, 线性, 范围 0 ~ 1
- **Y 轴**: Kawasaki (queen–vacancy exchange) 接受率, 线性
- **内容**: 6 条曲线 (N = 8, 16, 32, 64, 100, 128)

### 物理结论

1. **低温冻结**: T/J < 0.1 时接受率趋于零。系统处于基态构型（N-queens 解），几乎所有 Kawasaki 交换都会导致皇后冲突而被拒绝。

2. **单调递增**: 接受率随温度单调增长，在 T/J = 1 时达到约 0.40–0.47，反映高温时系统约束减弱，更多交换变得能量可接受。

3. **有限尺寸效应**: N = 8 的接受率在所有温度下显著高于其他尺寸（T = 1 时约 0.47 vs 0.40），因为小棋盘上皇后密度低、约束弱。N ≥ 32 后曲线基本重合，表明接受率已趋近热力学极限。

4. **N = 16 异常**: N = 16 的接受率在中高温区（T/J > 0.5）略高于 N = 32 ~ 128 的收敛值，说明 N = 16 仍有明显有限尺寸修正。

---

## Panel (b) — 积分自相关时间 (τ_int) vs T/J

- **X 轴**: T/J, 线性, 范围 0 ~ 1
- **Y 轴**: 能量的积分自相关时间 τ_int (sweeps), **对数刻度**
- **内容**: 6 条曲线 (N = 8, 16, 32, 64, 100, 128)

### 物理结论

1. **低温峰**: τ_int 在 T/J ≈ 0.075 ~ 0.10 处出现尖锐的峰值。这是因为低温时接受率极低，系统在相空间中的扩散极其缓慢，导致能量序列强烈相关。

2. **峰值随尺寸增长**: 峰值高度随 N 显著增大：
   - N = 8:   τ_int ≈ 300 sweeps
   - N = 16:  τ_int ≈ 3,700 sweeps
   - N = 32:  τ_int ≈ 5,900 sweeps
   - N = 64:  τ_int ≈ 13,000 sweeps
   - N = 100: τ_int ≈ 16,000 sweeps
   - N = 128: τ_int ≈ 18,000 sweeps

   这意味着大系统在低温区需要更多 sweeps 才能生成独立样本。

3. **快速衰减**: T/J > 0.2 后 τ_int 迅速下降。T/J > 0.4 时所有尺寸的 τ_int ≈ 5 ~ 10 sweeps，表明系统在中高温区的去相关效率很高。

4. **T = 0.05 的异常低值**: 最低温度点 T/J = 0.05 时 τ_int ≈ 0.5 sweeps，这是人为效应——因为接受率严格为零，能量序列恒为常数，形式上没有自相关。

5. **收敛性验证**: 即使在峰值 τ_int ≈ 18,000 sweeps (N = 128) 的情况下，10^8 sweeps 的测量仍提供约 5,500 个独立样本（10^8 / 18,000），足以保证统计精度。这证实了模拟在所有温度和尺寸下均已充分收敛。

---

## 低温长自相关时间不影响物理结论的论证

τ_int 的峰值出现在 T/J ≈ 0.075，而比热峰位于 T* ≈ 0.225 J，两者并不重合。下面从三个角度证明低温长自相关对结果没有影响：

### 1. 比热峰区域的 τ_int 很短且不随 N 增长

在 Cv 峰值 T ≈ 0.225 J 处，各尺寸的 τ_int 为：

| N | τ_int (sweeps) | 独立样本数 (10^8 / τ_int) |
|---|---|---|
| 8 | 179 | 558,700 |
| 16 | 198 | 505,100 |
| 32 | 147 | 680,300 |
| 64 | 135 | 740,700 |
| 100 | 134 | 746,300 |
| 128 | 133 | 751,900 |

τ_int ≈ 130–200 sweeps，几乎与 N 无关，且 10^8 sweeps 在此温度下产生超过 50 万个独立样本。这远超精确测量 Cv 峰高和峰位所需的统计量。因此，物理上最重要的 Schottky 峰区域具有极高的统计精度。

### 2. 低温区物理量本身无变化，长 τ_int 无实际影响

τ_int 峰值所在的 T/J ≈ 0.075 处，系统几乎完全冻结在基态：
- 接受率 ≈ 10^{-5}（N = 128），能量波动极小
- E/M 已收敛至基态值 E_0/M ≈ 0，Cv/M ≈ 0
- 物理量的涨落本身可忽略不计，其相对误差即使用较少的独立样本也能控制在很高精度内

换言之：长自相关时间的温度区域恰好是物理量最"无聊"的区域——能量和比热都趋于零且没有结构，根本不需要高精度采样。

### 3. 即使在最坏情况下，独立样本数仍然充足

在 τ_int 最大处 (N = 128, T = 0.075, τ_int ≈ 18,000)：
- 独立样本数 = 10^8 / 18,000 ≈ 5,500
- 统计误差 ∝ 1/√5500 ≈ 1.3%
- 此精度对于测量趋于零的物理量已绰绰有余

---

## 整体结论

Fig. 2 证实了蒙特卡洛模拟的可靠性：
- 接受率在感兴趣的温度范围内保持非零（T/J > 0.1），算法能够有效采样相空间；
- 自相关时间虽然在低温有峰值，但始终有界且远小于总测量步数，确保了统计误差的可控性；
- **关键**: τ_int 峰（T ≈ 0.075 J）与 Cv 峰（T ≈ 0.225 J）不重合。在物理上最重要的比热峰区域，τ_int 仅 ~130–200 sweeps 且不随 N 增长，每个温度点有超过 50 万个独立样本，统计精度极高；
- 有限尺寸效应在 N ≥ 32 后基本可忽略，物理量已趋近热力学极限。
